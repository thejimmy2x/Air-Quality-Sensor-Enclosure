# Sensor Stack Enclosure

Parametric, lidded desk enclosure for a multi-sensor air-quality stack, designed in
Fusion 360 (driven by User Parameters) for FDM printing (PETG/ASA, 0.6 mm nozzle).

## Sensor stack
| Board | Size (mm) | Role |
|---|---|---|
| ESP32-S3-DevKitC-1 | ~70 × 28 × 13 | MCU, heat source, external USB-C |
| PMS5003 | 50 × 38 × 21 | Particulate, fan, needs fresh ambient air |
| SCD40 (Adafruit) | ~26 × 18 × 8 | CO2, heat-sensitive |
| BME680 (Adafruit) | ~25 × 18 × 6 | VOC/T/RH/P, heat-sensitive |
| SGP40 (Adafruit) | ~25 × 18 × 5 | VOC index |

## Design
- **External:** ~155 × 83 × 39 mm. Low, wide slab; hex-honeycomb vents; filleted
  corners; chamfered floating base.
- **Thermal zoning:** hot back (PMS + ESP32) vs. cool front (gas sensors); SCD40
  placed farthest from heat.
- **Airflow:** passive honeycomb venting (front + both sides) for the gas sensors;
  PMS5003 isolated with a dedicated round fan-intake port + exhaust on the back wall.
- **Closure:** screw-down lid, M3 heat-set brass inserts (4 corners).
- **Features:** external USB-C port, status-LED light-pipe, removable carrier tray.

## Components (print each once)
- `export/base.3mf` / `.stl` — outer shell with vents, ports, insert bosses
- `export/tray.3mf` / `.stl` — removable sensor carrier (pockets, PMS/ESP cradles)
- `export/lid.3mf` / `.stl` — screw-down lid
- `export/sensor_enclosure_assembly.step` — full assembly (CAD interchange)
